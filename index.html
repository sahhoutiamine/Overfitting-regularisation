Overfitting et
Régularisation

Comprendre le surapprentissage et construire des modèles qui généralisent bien.

Un modèle performant doit être capable de faire de bonnes prédictions sur des données qu'il n'a jamais vues.

Qu'est-ce que l'Overfitting ?

Définition

Un modèle apprend trop bien les données d'entraînement.

Il apprend les vraies relations
Mais aussi le bruit (noise)

Résultat

Excellentes performances (Train)

Mauvaises performances (Test)

L'analogie de l'étudiant

La Régularisation

Ajouter une pénalité lorsque les poids deviennent trop grands.

Lasso L1

  • Supprime certaines variables (poids = 0)
  • Sélection automatique des features

Ridge L2

  • Réduit les poids proportionnellement
  • Garde toutes les variables actives
